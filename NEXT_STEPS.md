# Home, Wiz and authenticate-flow fixes

Home stays first. The music source editor now has a centered, opaque dialog and an integrated touch keyboard. Paths support lowercase letters, slashes, punctuation and spaces, plus paste, clear and UTF-8 deletion. ImGui's hidden-label inputs use their requested width instead of the old half-row layout. Home measures the taller Drive card and scrolls the dashboard without a visible scrollbar when it does not fit.

Drive replaces the Spotify/YouTube Music app controls. The default shared source is [MUSIC](https://drive.google.com/drive/folders/1Hd0PK3TO8rm4JkWfNZpwCmtHKvxgzh0T). Select **Home → Drive** to load it automatically, open **Library** to search/select songs, and use the folder button to paste another public Drive folder or audio-file link. No redirect URI or account sign-in is needed. Catalogs survive restarts. Selected tracks download to the app-owned hidden cache before MediaPlayer plays them; the stop button cancels a pending download. Refresh updates the song list and preserves the active selection when still present. A failed refresh leaves the previous catalog usable.

The Drive client accepts MP3, M4A, AAC, OGG, WAV and FLAC files directly inside the shared folder (256 tracks, 64 MiB per file, 192 MiB cache). It verifies HTTPS certificates with bundled Mozilla roots, limits redirects to Drive/Google download hosts and rejects preview/login pages and non-audio payloads. Public folder discovery uses Google's embedded-folder HTML, which can change; private folders, shortcuts, nested folder traversal and download confirmation/captcha pages are unsupported. Cached tracks are reused until evicted. Replace an edited song with a new Drive file when you need an immediate audio update; refreshing does not invalidate existing audio bytes.

Creamy UI sounds are original synthesized warm pops, droplets, soft swishes and a success chime. **Settings → Creamy UI sounds / Effects volume / Preview sound** controls them independently of music. Preferences are saved in the app's Music directory. Synthesis, OpenSL ES, network access, downloads and disk writes run off the render thread. Cue voices are bounded; rapid taps are limited, vertical scrolling is silent, and slider cues occur on edited release. Authentication cues follow stage changes once, including reduced motion.

The ESP preview uses Wiz rendered from the exact Glayer3d model the user supplied. Its existing breathing, hair, jump/cheer and secondary-motion animation now uses anchors adjusted to Wiz. The rendered PNG stays cached; there is no FBX import or frame-by-frame image decoding on Android. Attribution, source hashes, the noncommercial license and reproduction instructions are in [WIZ_LICENSE.md](src/main/jni/Assets/WIZ_LICENSE.md).

The weapon configuration layout now matches the provided 1.6.59 dump: `IsDouble` is at `0x44`, the mount type at `0x48`, color text at `0x50`, camo data at `0x58`, description at `0x60`, and name at `0x68`. Name lookup runs once before applying a skin and skips a missing name. The previous layout targeted camo data when trying to change the name.

Authentication now uses the offscreen refraction compositor in the actual Android render path. The card and all glass callbacks are composited together before the suck-in transform. The shrinking card stays clear of viewport edges, and the explosion uses a continuous irregular front, bounded displacement, RGB source separation and a transparent warm interior. Production preserves the current game backdrop; the GPU harness uses a checkerboard to expose refraction. The old drawn explosion outlines were removed. The authenticate button has centered text and no icon. Its pill collapses into a circular spinner, and the same ring closes and morphs into the drop before the fall and splash. The glass surface fades with the morph and returns as the drop falls. The drop squashes into the impact instead of being replaced abruptly. The white fill uses one shared strip mesh through both rounded ends. The previous separate arc fans left triangular holes between each end and the center; exterior-only clipping checks did not detect those holes.

All existing named phase durations stay in `StartupState.h`. The calm interval is 8050–8400 ms; loading reveals at 8400 ms and settles at 8850 ms. The extra 750 ms is the settled review hold, ending at 9600 ms.
